## How to Use All Features

### Generate Code
1. Enter prompt in sidebar
2. Click "Generate Code"
3. Preview shows automatically

### Edit with AI Chat
1. Type request in chat input
2. Press Enter or click Send
3. Code updates automatically

### View/Edit Code
1. Click "Show Code" button
2. Code editor slides in from right
3. Edit code directly
4. Preview updates automatically

### Rename Files
1. Double-click file or folder name
2. Type new name
3. Press Enter to save

### View Console Logs
1. Click "Console" tab
2. See all logs from generated code
3. Color-coded by type

### Use Conversation History
1. Previous prompts appear in sidebar
2. Click any prompt to reload it
3. Click "Generate Code" to use it

### Fix Errors
1. If errors appear, click "AI Fix"
2. AI automatically fixes the code
3. Preview updates with fixed code
